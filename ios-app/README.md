# ویرا برای آیفون (Capacitor)

همین فایل‌های اکستنشن (`index.html`, `css`, `js`, `vendor`, `fonts`) داخل یک WebView نیتیو بسته‌بندی می‌شوند.
برای ساخت لازم نیست مک داشته باشید؛ سرور مک GitHub Actions فایل IPA امضا‌نشده را می‌سازد.

## ساخت IPA

1. پوشهٔ اصلی پروژه (`vira ex`) را در یک ریپوی GitHub بگذارید (`.gitignore` پوشهٔ `mcp-servers` را کنار می‌گذارد).
2. در GitHub بروید به **Actions → Build unsigned iOS IPA → Run workflow**.
3. بعد از پایان (حدود ۱۰ دقیقه)، از بخش Artifacts فایل `Vira-unsigned-ipa` را دانلود و از حالت zip خارج کنید. داخلش `Vira-unsigned.ipa` است.

## نصب روی گوشی (ویندوز)

1. نسخهٔ iTunes و iCloud را **از سایت اپل** (نه Microsoft Store) نصب کنید.
2. **Sideloadly** یا **AltStore** را نصب کنید، گوشی را با کابل وصل کنید و Trust بزنید.
3. فایل IPA را با Apple ID خودتان نصب کنید.
4. در گوشی: Settings → Privacy & Security → **Developer Mode** را روشن کنید و گوشی را ریستارت کنید.
5. Settings → General → VPN & Device Management → Apple ID خودتان را Trust کنید.

اکانت رایگان اپل: گواهی هر ۷ روز منقضی می‌شود، حداکثر ۳ اپ فعال، و پوش نوتیفیکیشن ندارد.
تمدید خودکار با AltServer کار می‌کند به شرط اینکه AltServer روی ویندوز باز باشد و گوشی و کامپیوتر روی یک وای‌فای باشند.

## چه چیزهایی در اپ کار نمی‌کنند

این‌ها فقط در اکستنشن کروم معنی دارند و در اپ غیرفعال‌اند (کد با شرط چک می‌کند و خطا نمی‌دهد):

- حالت تمرکز (مسدودسازی سایت‌ها)، آمار زمان سایت‌ها، نمایش CPU/RAM
- نوتیفیکیشن‌های پس‌زمینه و آلارم‌ها
- دکمهٔ دانلود روی عکس و ویدیوی سایت‌ها و افزونهٔ GitHub
- ذخیرهٔ فایل در دانلودر: در WKWebView دانلود blob کار نمی‌کند و فایل در تب جدید باز می‌شود

درخواست‌های شبکه (قیمت‌ها، فهرست نشت، سرور ویرا) با افزونهٔ HTTP نیتیو Capacitor ارسال می‌شوند تا محدودیت CORS نداشته باشند.

## ساخت محلی برای بررسی

```bash
cd ios-app
npm install
npm run build:www   # فقط پوشهٔ www را می‌سازد
```

ساخت خود اپ فقط روی مک (یا GitHub Actions) ممکن است.
